# Industrial Engineering Lab

A personal software laboratory focused on industrial engineering, manufacturing, maintenance, reliability, and process improvement.

## Current Project

### Industrial Maintenance Calculator

A simple C# console application that estimates the financial impact of machine downtime.

The calculator takes:

- Downtime per incident (hours)
- Cost per downtime hour (€)
- Number of incidents per month

And calculates:

- Cost per incident
- Estimated monthly downtime cost
- Estimated annual downtime cost

## Technologies

- C#
- .NET
- Git
- GitHub

## Example

Input:

- 6 hours of downtime
- €150 per hour
- 4 incidents per month

Result:

- €900 per incident
- €3,600 per month
- €43,200 per year
